# Agentes

Agents atuam somente no próprio domínio, inspecionam o projeto antes de criar arquivos, reutilizam componentes e preservam contratos públicos.

- `product-master.md` define decisões normativas; `product-v1.md` define o recorte atual; `content-grade5.md` define o conteúdo publicado de 5º ano.
- Nunca transformar item pendente em regra definitiva. Marcar `PENDENTE DE PRODUTO`.
- Não duplicar engine de atividade, acessar Firebase/Hive na UI ou inventar XP, nota, domínio, economia, streak ou mascote.
- Agents de conteúdo não copiam materiais proprietários e devem adaptar linguagem à série.
- Segurança e integridade de dados têm prioridade sobre conveniência de implementação.
- Mudanças arquiteturais amplas exigem justificativa e testes proporcionais ao risco.
